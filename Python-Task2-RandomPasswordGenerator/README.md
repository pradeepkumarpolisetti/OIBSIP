# Random Password Generator

A simple Python program that generates random passwords based on the user's selected character types and password length.

## Features

- User can choose password length
- Minimum password length is 8 characters
- Supports uppercase letters
- Supports lowercase letters
- Supports numbers
- Supports symbols
- Generates a random password
- Option to generate another password

## Technologies Used

- Python
- Random module
- String module

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run:

python project.py

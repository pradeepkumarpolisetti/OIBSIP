# Basic Weather App

A simple Python application that fetches and displays current weather information for a city using a weather API.

## Features

- Takes a city name as input
- Displays temperature in Celsius
- Displays temperature in Fahrenheit
- Displays humidity
- Displays weather conditions
- Displays wind speed
- Handles invalid city names
- Handles network errors

## Technologies Used

- Python
- Requests library
- Weather API

## How to Run

1. Install Python.
2. Install the Requests library:

pip install requests

3. Get a weather API key.
4. Replace `YOUR_API_KEY` in `project.py` with your API key locally.
5. Run:

python project.py

## Note

For security reasons, the API key is not included in this repository.

# BMI Calculator

A simple Python program that calculates Body Mass Index (BMI) based on the user's weight and height.

## Features

- Takes weight in kilograms
- Takes height in metres
- Calculates BMI
- Displays the BMI category
- Handles invalid input

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run the following command:

python project.py

## BMI Categories

- Below 18.5: Underweight
- 18.5 to 24.9: Normal
- 25 to 29.9: Overweight
- 30 and above: Obese
